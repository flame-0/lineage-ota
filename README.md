# lineage-ota

## structure

- `<device>.json` – ota update metadata for a device (generated by `update.py`)
- `index.json` – aggregated device list for the download page (updated by `sourceforge_upload.sh`)
- `sourceforge_upload.sh` – uploads rom zip + images to sourceforge, generates `<device>.json`, updates `index.json`
- `update.py` – creates `<device>.json` from a url (or local file)
- `index.html` – download page (fetches `index.json`)

## setup

1. create a sourceforge project and enable ssh access
2. edit `sourceforge_upload.sh` and set `PROJECT` and `SF_USER`
3. edit `index.html` and set `projectName` to the same value as `PROJECT`
4. install `rsync` and python dependencies: `pip install requests tqdm`

## usage

```sh
./sourceforge_upload.sh lineage-23.2-20260828-amogus-alioth-signed.zip boot.img vendor_boot.img dtbo.img
```

this will:
- upload the rom and images to sourceforge under `<project>/<device>/<date>/`
- generate `<device>.json` (ota metadata for the updater)
- update `index.json` (data for the download page)

## ota updater

in your lineageos build, set:

```xml
<string name="updater_server_url" translatable="false">https://raw.githubusercontent.com/YOUR_USERNAME/lineage-ota/lineage-23.2/{device}.json</string>
```
