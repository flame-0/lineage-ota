# lineage-ota

## structure

- `<device>.json` - ota update info for a device (generated by `update.py`)
- `index.json` - aggregated list of all devices for the download page (updated automatically by `sourceforge_upload.sh`)
- `sourceforge_upload.sh` - uploads rom zip + images to sourceforge, generates `<device>.json` and updates `index.json`
- `update.py` - creates `<device>.json` from a url (or local file)
- `index.html` - download page (fetches `index.json`)

## setup

1. create a sourceforge project and enable ssh access
2. edit `sourceforge_upload.sh` and set your project name and username
3. install `rsync` and python dependencies: `pip install requests tqdm`

## usage

### build and upload

```sh
./sourceforge_upload.sh lineage-30.5-99967999-amogus-onyx-signed.zip boot.img dtbo.img balls.img
```
